## Phase 0（2026-11-21）

- Gradle は、アプリに必要な部品を集め、動く形に組み立てる道具です。
- APK は、Android がアプリをインストールするためのファイルです。
- エミュレーターは、Mac の中で動かせる仮想の Android スマートフォンです。
- adb は、Mac からスマートフォンにアプリのインストールや画面の撮影を指示する道具です。

## Phase 1（2026-11-21）

- Jetpack Compose は画面を組み立てる仕組みです。Material 3 で文字の大きさや配色を揃え、端末のダークモードにも合わせました。
- Navigation Compose は、Bot 一覧からチャットを開いたり、元の画面に戻ったりする道順を管理します。
- ViewModel は通信の結果を持ち、端末を回転しても画面が同じ情報を表示できるようにします。
- OkHttp は Mac mini に情報を取りに行き、kotlinx.serialization は届いた JSON をアプリで扱えるデータに変換します。

## Phase 2（2026-11-21）

- 入力欄は文章が増えると5行まで広がります。キーボードが開いても、入力欄と送信ボタンを操作できます。
- 選択肢を押すと、実際に送る答えを確認する画面が開きます。「はい」を押すと Bot に届きます。
- 送信中はボタンを押せなくして、通信が途中で切れても自動で送り直さないようにしました。
- 送れたか分からないときは入力を残します。会話を更新すると、Bot に届いたかを自分で確認できます。

## Phase 3（2026-11-21）

- WorkManager は、アプリを開いていない間も、Android に約15分ごとの確認を任せられる仕組みです。
- 通知チャンネルを「判断待ち」と「まとめ」に分けたので、Android の設定で種類ごとに通知を調整できます。
- Android 13 以降では、通知を表示するために利用者の許可が必要です。
- PendingIntent は、通知をタップしたときに Android が該当する画面を開くための仕組みです。

## Phase 4（2026-11-21）

- テーマは、背景や文字の色、文字の大きさや太さ、角の丸みをまとめて持つ仕組みです。端末の明るさ設定に応じて見た目が切り替わります。
- Orca のマスコットは、ぼかしなどを残せるように画像へ変換してアプリに入れました。表示する画像は Bot ごとの設定で決まります。
- ランチャーアイコンは Android のホーム画面でアプリを示します。通知には、小さくても形が分かる Orca の白いシルエットを使いました。
